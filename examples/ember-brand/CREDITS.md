# Asset provenance

This kit contains original schematic vector artwork and documentation authored
for the `video-factory` example. No external brand logos, stock media, downloaded
fonts, model-generated images, or audio tracks are bundled.

| Asset | Source |
|---|---|
| Pip artwork and poses | Editable definitions in `source/mascot.svg` |
| Primary mascot, turnaround, expressions, poses | Generated from the source definitions by `build_assets.py` |
| Flame mark and wordmark lockup | Source flame symbol plus configured live text |
| Background plate | Geometric SVG generated by `build_assets.py` |
| Brand board | Local HTML/CSS/JavaScript with system font stacks |

When adapting this kit, replace this register with actual sources, owners, usage
permissions, and approval dates. The repository's licensing context is described
in [`THIRD_PARTY.md`](../../THIRD_PARTY.md).
